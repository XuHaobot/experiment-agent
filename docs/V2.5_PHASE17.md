## 1. 为什么需要 Research Memory 2.0？

在传统 AI 记忆系统中，大模型通常将所有历史对话、用户输入与实验摘要一并混合存储，导致以下科学认知缺陷：
1. **AI 认知固化与回音室 (Epistemic Lock-in)**：AI 越使用过去的历史数据，就越倾向于相信过去的选择（例如在局部最优参数附近反复微调），忽略了潜在的盲区或矛盾证据；
2. **状态混淆 (Epistemic Confusion)**：将 AI 生成的推测性假说（`AI_SUGGESTION`）误当成已证事实（`FACT`），并作为后续推演的前提；
3. **负向知识抹除**：失败或报错的实验往往被过滤遗忘，导致重复踩坑。

**Research Memory 2.0 的核心突破**：
建立**分级认识论状态 (Epistemic Status)** 与**证据天平 (Evidence Balance)**，主动探测**未探索空间 (Unexplored Space)** 并生成**竞争性机制假说 (Alternative Hypotheses)**，让 AI 成为发现未知盲区的科研推演工作台。

## 2. 核心架构与新增组件

### 2.1 10 级 Epistemic Status (`backend/domain/epistemic.py`)
```text
OBSERVATION        ─> 来自实验与遥测的直接客观观测 (k=20, acc=0.91)
FACT               ─> 经多重独立复现与证据充分支持的既定事实
EVIDENCE           ─> 支撑或反驳具体假说的证据切片
INTERPRETATION     ─> 对证据/现象的归因解释 (非既定事实)
HYPOTHESIS         ─> 待验证的研究假说
CONCLUSION         ─> 基于证据天平汇总形成的阶段性结论
FAILED_EXPERIMENT  ─> 失败或异常中断的实验 (永久保留的负知识)
ASSUMPTION         ─> 当前默认接受但未系统检验的先验前提
USER_BELIEF        ─> 科研人员个人的主观反思与直觉观点 (不可自动升级为事实)
AI_SUGGESTION      ─> AI 提供的推测性假说或建议 (严禁自动升级为事实)
```

### 2.2 证据天平 (Evidence Balance)
* `build_evidence_balance(project_id, hypothesis_id=None)`：
  - 汇总 `supporting`（支持性证据与高指标 Run）与 `contradicting`（反面证据、性能回落或失败运行）；
  - 科学置信度基于证据正反比例客观评定（`high` / `medium` / `low`），严禁使用 LLM 幻觉出的伪科学概率数字（如 "93.4%"）。

### 2.3 未探索参数空间探测 (Unexplored Space Discovery)
* `discover_unexplored_space(project_id)`：
  - 自动扫描历史 Runs 的参数取值；
  - 精准识别大跨度测试空隙（如测试了 $k=10, 20, 30$，自动发现 $[11, 19]$ 与 $[21, 29]$ 盲区）；
  - 识别外推边界（如 $>30$）与多变量交互盲区。

### 2.4 竞争性机制假说 (Alternative Hypotheses Engine)
* `generate_alternative_hypotheses(project_id)`：
  - 当观测到异常或性能拐点时，不再只输出单一归因（如“过平滑”），而是主动生成竞争性假说（如“数据分布偏移”、“学习率交互效应”、“随机初始化敏感度”）；
  - 严格标记为 `AI_SUGGESTION`，并标明 `reasoning_basis` 与是否为推测性质（`is_speculative`）。

### 2.5 下一代实验推荐联动 (`backend/domain/next_experiment.py`)
* 推荐逻辑由单纯的“预测最高指标”进化为“**最大化科研信息增益 (Information Gain) 与不确定性消除 (Uncertainty Reduced)**”；
* 候选实验优先针对未探索空间中段进行采样；
* 严格排查历史已执行参数签名，**坚决不重复已完成的实验配置**。

## 3. REST API 接口定义

| Method | Endpoint | Description |
| :--- | :--- | :--- |
| `POST` | `/api/projects/{id}/memory/ask` | 认知记忆智能问答，输出支持/反面证据、备选假说与未探索空间 |
| `GET` | `/api/projects/{id}/memory/balance` | 获取课题或指定假说的正反证据天平与置信充分度 |
| `GET` | `/api/projects/{id}/memory/unexplored` | 获取课题超参数与物理维度的未探索盲区清单 |
| `GET` | `/api/projects/{id}/memory/alternatives` | 获取针对当前指标表现的竞争性机制假说列表 |

## 7. 已知限制与 Phase 18 演进建议

1. **当前限制**：
   - 竞争性假说生成基于科研规则库与领域先验模板驱动；对于极其非线性的高维多变量交叉交互，建议在 Phase 18 引入物理守恒方程与多源符号回归验证器。
2. **Phase 18 演进建议**：
   - **Exploration Engine（自主科学探索引擎）**：结合 Bayesian Optimization / Active Learning 对 `unexplored_space` 进行自动不确定性采样排序。
   - **Epistemic Pruning（认识论修剪器）**：当新证据直接否定旧假说时，自动标记下游结论并提示科研人员复核。
